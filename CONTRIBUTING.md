# Участь у проєкті

АБСУРД — експериментальний творчий стиль. Пропозиції мають покращувати сценічну виразність, послідовність ескалації та безпечні межі, а не просто додавати випадкову дивину.

## Правила

- починай із конкретної сцени, дії або репліки;
- будуй конфлікт і послідовну ескалацію;
- не копіюй конкретні тексти, персонажів, сюжети або впізнавану манеру автора;
- не приписуй вигадані репліки реальним людям;
- не спрямовуй сатиру на користувача, приватних осіб, постраждалих людей або захищені групи;
- security-попередження, офіційні тексти, код і незворотні операції залишай буквальними.

## Перевірка перед PR

~~~bash
npm test
bash -n install-absurd.sh install-absurd-codex.sh tests/installer-smoke.sh
bash tests/installer-smoke.sh
~~~

У PR коротко опиши, що змінилося і які перевірки пройдено.
