# Безпека

АБСУРД містить інсталятори, які записують файли до каталогів Codex і Claude Code.

Перед запуском інсталятора:

- використовуй релізний тег або конкретний commit SHA;
- переглянь скрипт і перевір змінні ABSURD_REF, TARGET_CODEX_DIR та TARGET_CLAUDE_DIR;
- для тестування використовуй окремий каталог;
- не передавай у команди ключі, паролі чи інші секрети.

## Повідомлення про проблему

Не публікуй у відкритих issues деталі, які містять секрети або дають змогу змінювати чужі файли. Для приватного повідомлення використай GitHub Security Advisories репозиторію.

У повідомленні вкажи:

1. уражений файл і версію або commit;
2. передумови відтворення;
3. фактичний вплив;
4. безпечний спосіб перевірки без секретів.
